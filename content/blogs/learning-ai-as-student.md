Entering Computer Science and Engineering with a focus on Artificial Intelligence and Machine Learning opens up a world of fascinating problems. As a 3rd-year BTech student, here are some key insights I've learned along the way:

## 1. Build Alongside Theory

It is easy to get caught in endless tutorial loops or reading research papers without implementing anything. The turning point in my learning happened when I started writing code for small, concrete projects: training simple classifiers, testing predictions on real datasets, and creating interactive user interfaces with Streamlit.

## 2. Models Need Interfaces

A trained machine learning model inside a Jupyter Notebook is an experiment, but it isn't an accessible solution yet. Learning web technologies (HTML, CSS, JavaScript, APIs) enables you to turn scripts into actual applications that peers and non-technical users can interact with.

## 3. Focus on Real-World Problems

The most exciting applications of AI aren't abstract benchmarks—they're tools that solve everyday pain points, such as civic complaint management, intelligent document summarization, and accessible education tools. 

I'm excited to continue building, experimenting, and growing as an engineer!
